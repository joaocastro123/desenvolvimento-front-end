Esse é o meu primeiro projeto na disciplina de desenvolvimento front end para web, nesse estou criando uma pagina para um sit de uma ong o projeto tem algumas exigencias como desenvolver um conjunto de pagina web para uma ONG contento pagina inicial(apresentação),pagina de projetos, e cadastro 

estrutura semântica e paginas

O foco agora será organizar os diretórios locais do projeto e implementar os alicerces estruturais em cada arquivo que compõe a aplicação, mantendo a hierarquia correta de navegação e garantindo que cada seção forneça significado computacional claro para leitores de tela e robôs de busca.

Objetivos da etapa
Ao final desta etapa, espera-se que o(a) estudante seja capaz de:

Estruturar o ambiente de desenvolvimento, definindo pastas distintas para arquivos HTML e de imagens;

Implementar o esqueleto fundamental de três páginas HTML semânticas utilizando tags adequadas;

Assegurar a correta hierarquia da informação no conteúdo textual da página inicial e da página de projetos sociais.
